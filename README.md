# waytinyime

面向 Wayland 与 Xwayland 的原生中文码表输入法，支持 fcitx5 码表、中文标点和 Emoji 分类输入。

## 已有功能

### 码表与选词

- 读取 fcitx5 码表配置，支持 libime/fcitx5 的 UTF-8 文本码表和二进制主词库；没有外部配置时回退到内置小鹤码表。
- 支持精确匹配、前缀匹配、翻页、数字选词、候选游标移动，以及按码表配置自动选词。
- 支持码表中的组词规则和预定义词组；只读使用主词库，不读取或修改用户词库、历史和学习数据。
- 反引号作为单字母通配符，可放在编码任意位置；按输入码长查询，候选附带完整编码，不自动上屏。

### 中英文输入与标点

- `Ctrl+Space` 切换中英文；切换前先原样提交未完成编码，不自动选词或丢弃内容。
- 中文模式下，空格选择当前候选，数字选择当前页候选；Enter 原样提交编码，Backspace 编辑，Esc 取消。
- 无匹配编码可继续输入和编辑，不在最大码长处强行拆分，便于直接输入英文单词。
- 中文模式自动转换全角标点，支持引号配对、书名号、省略号、破折号，以及斜杠和反斜杠输入顿号。
- 标点前先提交当前候选，无候选时提交原始编码；有效的编码、选词和翻页绑定优先于标点转换。
- 英文模式直通半角字符，Ctrl/Alt/Super 快捷键不转换。

### Emoji 分类输入

- `oj` 浏览总览，`oja`–`ojz` 进入 26 个分类，共 1384 个不重复 Emoji，详见 [分类速查](docs/emoji-codes.md)。
- 支持翻页、游标和数字选词，Backspace 返回总览；不会自动提交目录首项。
- 保留原码表：`oj` 已占用时禁用整个入口，分类码冲突时保留原候选，不覆盖已有字符，也不改用其他空码。内置码表的 `oj` 已被占用，因此不启用 Emoji 入口。
- 候选窗支持 Emoji 字体回退和彩色字形；当前不包含肤色组合、ZWJ 连字、组合国旗或键帽序列，字形显示取决于字体与客户端支持。

### Wayland 与 Xwayland 候选窗

- 原生 Wayland 上屏与候选弹窗，支持随插入点和窗口移动、按合成器建议的整数倍率高清渲染。
- Xwayland 通过 XIM 提供上屏、预编辑和候选窗；支持客户端提供的光标位置，没有位置信息时降级定位。
- 两类前端共用中英文模式；提交、取消和失焦时清理组合与候选窗，切换前端不遗留未完成输入。
- 使用系统中文字体，不重复显示应用预编辑中的编码；XIM 客户端未采用预编辑回调时在候选窗保留编码。
- Wayland 依赖合成器支持输入法与候选弹窗协议，不保证兼容所有桌面环境；XIM 的定位精度、缩放和 Emoji 显示也受客户端与合成器限制。
